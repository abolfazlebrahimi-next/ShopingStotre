🎨 پیش‌نمایش استاتیک طراحی ShopingStore

این پوشه شامل چند صفحه HTML استاتیک است که با همان CSS و فونت پروژه دات‌نتی ساخته شده‌اند تا بدون اجرای دات‌نت، ظاهر و تجربه کاربری فروشگاه و پنل مدیریت را ببینید.

  • صفحه اصلی (خانه، دسته‌بندی‌ها، کارت محصولات، صفحه‌بندی، نظرات)
  • صفحه جزئیات محصول (گالری، تنوع، مشخصات، نظرات، محصولات مشابه)
  • سبد خرید (تغییر تعداد، کد تخفیف، خلاصه سفارش)
  • تکمیل خرید و درگاه پرداخت شبیه‌سازی‌شده
  • داشبورد پنل مدیریت (آمار، نمودار فروش، جداول)

نمایش پیش‌نمایش

این صفحه‌ها به CSS و فونت واقعی پروژه دات‌نت (مسیر نسبی ../src/ShopingStore.Web/wwwroot/) لینک می‌شوند، پس باید از ریشه مخزن سرو شوند. ساده‌ترین راه: 

python3 -m http.server 8000

سپس آدرس http://localhost:8000/preview/index.html را باز کنید.

نکته: برای دیدن نسخه واقعی و تعاملی، پروژه را با dotnet run --project src/ShopingStore.Web اجرا کنید (راهنمای کامل در README.md).
